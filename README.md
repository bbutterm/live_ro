# RO Live — живые жители Ragnarok Online

Новая реализация вместо прежнего live_ro. Старое содержимое удалено из текущего дерева, но история Git сохранена для отката.

## Цель
OpenKore исполняет ограниченные навыки, rAthena подтверждает фактические игровые события, один оркестратор ведёт журнал и планы. LLM позже выбирает только допустимые варианты. ACK команды — не успех в игре.

## Текущее состояние
**Поднятый лабораторный стенд, не готовые автономные жители.** Веха A: три сервера работают; вход тестера ещё не завершён; свидетеля пока нет. Точный handoff: [docs/STATUS.md](docs/STATUS.md) и [docs/HANDOFF.md](docs/HANDOFF.md).

## Исходники
- `tools/`: выполненные скрипты первоначальной настройки; только для новой изолированной установки. **Не запускать повторно на существующей базе.**
- `checks/01.py`: проверка процессов, локальных портов и таблиц; не доказывает игровой вход или межсерверную авторизацию.
- `ops/units/`: текущие определения изолированных systemd-сервисов, не включённых на загрузку ОС.
- `vendor/`: официальные зависимости как submodules с точными gitlinks; собственных изменений ядра нет.
- `docs/ro_residents_report/`: девять оригинальных проектных документов. Их целевые критерии не являются отчётом о выполнении.
- [Совместная работа нескольких ИИ](docs/COLLABORATION.md) и [готовые issues](docs/TASKS.md).

## Ограничения воспроизводимости
Скрипты сохраняют текущий путь лаборатории `/root/ragnarok/repos/rathena`, а submodule checkout использует `vendor/rathena`. Автоматического универсального инсталлятора ещё нет. Копирование шаблонов import, права сервисного пользователя и связывание systemd выполнялись отдельно. Не запускайте скрипты на другом хосте без изучения и настройки путей.

В `prepare_tester.py` ещё не сохранена runtime-поправка `addTableFolders kRO/RagexeRE_2018_06_21a;kRO`. Получатель этой таблицы использует тот же upstream receive-класс через наследование; полноценная совместимость пока не доказана игровым входом. PIN отключён на локальном стенде, не в исходном provision-скрипте. Изменения файлов через атомарную замену сбрасывают ACL: восстановить доступ `ro-residents` перед перезапуском.

## Проверки
```sh
python3 -m unittest discover -s tests -v
```
Проверка исходников не запускает серверы и не заменяет runtime-приёмку. Репозиторий не содержит ключей, локальных паролей, БД, сырых логов, клиентских GRF или бинарников. Изменение Git не является деплоем.
