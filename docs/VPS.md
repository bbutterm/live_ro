# VPS и обновления

Текущий runtime: `/opt/ro-bot-lab`, отдельный системный пользователь `ro-lab`.
Вне Git: `secrets/`, `state/`, `logs/`, MariaDB и локальные конфиги с авторизацией.

## Ручное получение кода
```sh
git fetch origin
git pull --ff-only origin main
git submodule update --init --recursive
python3 scripts/check.py
```
Выполнять в отдельном checkout, не поверх живой лаборатории. Записать предыдущий commit перед обновлением.

## Доставка
Автоматический apply/restart пока намеренно отсутствует: не перезаписывать живые конфиги без отделения секретов.
После ревью: собрать отдельную версию, сделать бэкап базы при миграциях, перенести только нужные настройки/бинарники, перезапустить только лабораторные процессы, проверить login/char/map и вход бота.
Для отката кода использовать предыдущий commit в отдельном checkout. Откат БД не автоматический.

## Секреты бота
Экспортированный config.txt без username/password. Перед запуском создать runtime-копию вне checkout и локально заполнить учётные данные. Не коммитить её. Серверные inter-server/SQL пароли также только локально.

## Текущее состояние
Сборка rAthena подтверждена. Полный запуск мира и вход бота не подтверждены. Brain не реализован. Этот репозиторий — исходная точка совместной разработки, не заявление о готовом AI-мире.
