## Известные ограничения
- checks/01.py проверяет процессы/порты/таблицы, не readiness и не auth. После повреждения прав он может PASS при сломанной межсерверной связи. Требуется усиление acceptance-check.
- Атомарное редактирование char_conf сбросило ACL пользователя сервиса. Исправлено восстановлением ACL и перезапуском только новых char/map; после каждой дальнейшей правки проверять readable под сервисным user.
- Баннер upstream читает refs/heads/master, а не detached HEAD: отображаемый Git Hash не соответствует истинному checkout. Источник истины — git rev-parse HEAD; ядро не правили.
- 'Characters per Account: 0' = unlimited, не отсутствие слотов.
- У PACKETVER 20180620 отключён Barter; стандартный NPC-loader сообщает это. Связанной функциональности здесь не требуется.
- Старый live_ro не восстановлен. Hermes, Telegram-боты и общая MariaDB не переустанавливались.

Сырые evidence и реестр процессов находятся только на VPS `/root/ragnarok`, не в публичном Git.
