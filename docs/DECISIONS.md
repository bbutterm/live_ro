# Решения
2026-10-10 — Подтверждённый native-prelude принадлежит цели, не каждой попытке движения: общий execute сохраняет prelude_outcome и не повторяет done при retry follow/walk/hunt. Неудавшаяся речь остаётся в прежней политике трёх попыток, сроки/чат/экономика не меняются; новая игровая ветвь retry после внедрения пока не появилась.
2026-10-10 — Подтверждён взаимный lock двух автономных meet: Mira timeout, ResidentA завершил встречу лишь после её освобождения. При занятости арбитра активная взаимная задача уступает по стабильному порядку имён: больший инициатор завершает failed(MEETING_COLLISION), меньший сохраняет свой голос/срок и ждёт обычный арбитр. Чужую задачу не переписываем, decline/чат выше столкновения, экономику не отменяем; новая игровая коллизия пока не наблюдалась.
2026-10-10 — Сервер выявил три двойных say Mira: модель одновременно указала args.text и say. В общем execute речевые say/whisper выполняют только свой native-навык, без публичного prelude; движение сохраняет речь. Это также исключает публичное раскрытие дополнительной реплики шёпота. Все brains обновлены под свободным manual-арбитром; живой say с обоими полями после внедрения ещё не появился. Повтор prelude при retry follow и взаимные одновременные meet отмечены отдельно, не объявлены исправленными.
2026-10-10 — Общая проверка порога регенерации повторяет native-плагин: rest запрещён при известном весе ≥50%; модель получает подсказку idle вместо невозможной регенерации. Fallback при низком HP/перевесе продаёт только прежний whitelist либо выбирает безопасный городской idle; смерть выше этих правил. Все brains обновлены через manual-арбитр, без отмены экономики; новые игровые rest/низкое HP в срезе не наблюдались, снятие перевеса не заявляем.
2026-10-10 — Модельный decline завершает meet независимо от доставки речи: один безопасный захват свободного manual-арбитра, без ожидания занятого writer; в meeting_reply отдельно сохраняем done/ошибку/неотправленную речь. Чат выше отказа, экономика не отменяется, встречное предложение сохраняет прежний срок. Живой accept после внедрения подтверждён; новая ветвь decline пока только make check.
2026-10-10 — После отдельного модельного голоса meet ждёт освобождения manual-арбитра второго жителя в пределах исходных пяти минут: модельная охота удерживает lock, мгновенный TARGET_BUSY терял настоящее согласие. Новый голос/срок не создаём, экономика не отменяется, чат прерывает ожидание; живое согласие и встреча подтверждены, отказ без озвучивания пока может закончиться timeout.
2026-10-10 — Таймаут общего SELECT tools.events.query переводим в RuntimeError без приватных деталей и цепочки traceback: штатные обработчики gateway/мозга получают безопасную ошибку чтения, курсор не сдвигается. Запущенные gateways не перезапускаем ради внедрения; новый импорт и восстановление в игре должны быть подтверждены отдельно.
2026-10-10 — Длительная история gateway требует индекса events(source,ts): миграция только локального SQLite ускоряет временные witness/chat/picklog выборки, не меняет факты, курсоры, деньги или действия; применена без перезапуска тел. Необработанный таймаут MariaDB остаётся отдельным следующим исправлением.
2026-10-10 — Живой ответ на автономный meet упёрся в APITimeoutError за 3 с: negotiate получает штатные 20 с, как мозг по ТЗ; respond игроку остаётся 3 с. Срок встречи 5 мин, сохранённые голоса, приоритет чата и бюджет не меняются; только brains обновляются под manual-арбитром.
2026-10-09 — Подтверждённый цикл снабжения из-за перевеса без добычи в whitelist прерываем безопасным idle у фонтана, не охотой и не rest с выключенной регенерацией; повторная проверка после пяти минут, чат сохраняет приоритет. Whitelist/предметы не меняем; снятие перевеса остаётся BLOCKED, обновлён только brain ResidentA через manual-арбитр.
2026-10-09 — Witness-память обновляется при выборе очередного занятия даже на бюджетной паузе; затвор запрещает лишь платную модель. Быстрые respond/negotiate не получают дополнительного SELECT с восьмисекундным таймаутом; возраст кэша во время долгого навыка не обещаем.
2026-10-09 — Ночное поручение: meet требует отдельный модельный accept/decline/counter второго жителя; один counter подтверждает отдельная модель инициатора, без fallback-согласия. Общий срок 5 минут, голоса сохраняются до вызова, повторов meet нет; шаблон речи лишь озвучивает модельный выбор. Чат обеих сторон прерывает маршруты, экономика не отменяется; бюджет открывается только штатно в UTC.
2026-10-09 — Без цели модели fallback добавляет подтверждённый городской визит/речь/5 минут отдыха, затем 15 минут до нового визита; здоровье и снабжение выше прогулки, чат прерывает и затем возобновляет отдых. Состояние отдельное у каждого жителя; бюджет не меняется.
2026-10-09 — P6: одноимённая локальная имитация 429 ограничена жителем и сроком, происходит до сетевого вызова/резервирования; диагностическое снятие только технической паузы не меняет финансового лимита. Откат инъекции — удалить llm-fault.json; действующий DAILY_LIMIT сохраняется.
2026-10-09 — Чат вынесен в отдельный ro-chat.service: задержка восстановления мозга не должна терять десятисекундные реплики; тела и ro-world.service не перезапускаем. Откат: встроенные слушатели после возврата chat_service=embedded.
2026-10-09 — Владелец разрешил сократить P4: основной прогон — ответ игроку, follow и встреча; полный набор 10 фраз пропускаем и не заявляем 10/10.
2026-10-09 — Для краткой приёмки BRAIN_HOLD до 20 минут приостанавливает только автономный выбор одного жителя; входящий чат и его действия остаются активными, тело и мир не выключаются.
2026-10-09 — P2 принимает ручной meet с подтверждённым предложением, ответом и двумя прибытиями; самостоятельные LLM-переговоры проверяются отдельно в P4, не приписываются модели.
2026-10-09 — Общий срок ручной проверки навыка ограничен 20 минутами, walk_to — одной минутой включая повторы; при неизвестном результате новая команда не отправляется.
2026-10-09 — Владелец ограничил все игровые проверочные прогоны 15–20 минутами; P3/P6 принимаем только по коротким активным сценариям, покрытие 2/12/24 часов не заявляем.
2026-10-09 — P1: владелец принял сокращённое наблюдение вместо полного часа и разрешил последующие проверки на ResidentA и Мире; Borin остаётся в мире, его не отключаем.
