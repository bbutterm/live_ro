2026-10-12 — В ночной ветке support/hunt_party после подтверждённого маршрута повторяют eligibility по новому gateway status и текущему resident_id; потеря party/свежести/learned Heal запрещает hunt, native witness/live службы не меняются.

2026-10-12 — В изолированной ночной ветке новые callable actions требуют явного числового возраста тела 0–4 с; неизвестный/некорректный возраст запрещает dispatch с STALE_BODY, witness/ownership и live службы неизменны.
2026-10-10 — По прямому разрешению владельца «забей на лимит пока»: временный общий cap 3 USD только для ResidentA, привязанный к token digest действующего controlled lease и исходному deadline <=20 минут; после released/expiry штатные 2 USD. Старые резервы/credentials не удалять, второй денежный журнал не создавать. Это отдельное разрешение, заменяющее прежний запрет рабочего override только в этом canary.
2026-10-10 — Владелец поручил зафиксировать текущую реализацию в Git и вынести все известные ошибки отдельно: RESULT_BEHAVIOR_V1.md описывает факты, ERRORS_BEHAVIOR_V1.md — открытые/исправленные проблемы; checkpoint не объявляет игровую приёмку завершённой.
2026-10-10 — LLM в V1 подключается только через отдельный opt-in, связанный с токеном действующего lease; до активации — fallback без платных вызовов. После ожидания модели обновляем серверный snapshot, повторяем safety/veto/ownership и только затем создаём motor outbox. Общий бюджет и неизвестные старые резервы не изменяются; игровая LLM-приёмка отдельна от тестового transport.
2026-10-10 — Исправление V1: время арбитража снимается после получения snapshot, чтобы новый кадр во время RPC не считался будущим/stale. service_possible требует разрешённого излишка либо недостающих 501 и денег на покупку: одни деньги при полных запасах не создают экономический план; это уточнение предотвращает пустые походы в магазин, whitelist/вещи/лимит не меняются.
2026-10-10 — Для включения V1 используем адресный canary одного жителя: неизменяемый lease ≤20 минут, fencing в gateway, отдельный fallback-brain и возврат legacy только после доказанного пустого native/outbox. ro-world и общий чат не перезапускаются; idle brain и только его gateway/OpenKore заменяются штатным восстановлением supervisor после проверки отсутствия активных действий. Остальные жители не затрагиваются.
2026-10-10 — Переговорный контекст включает текущую незавершённую задачу и число/возраст только свидетельских встреч за 15 минут; модель сама принимает/отказывает, без принудительного decline. Явный CANCELLED больше не повторяет обратимую цель. Неутверждённый рабочий override $3 убран, лимит $2 и старый финансовый журнал сохранены; платная приёмка ждёт штатного бюджета.
2026-10-10 — Подтверждённый native-prelude принадлежит цели, не каждой попытке движения: общий execute сохраняет prelude_outcome и не повторяет done при retry follow/walk/hunt. Неудавшаяся речь остаётся в прежней политике трёх попыток, сроки/чат/экономика не меняются; новая игровая ветвь retry после внедрения пока не появилась.
2026-10-10 — Подтверждён взаимный lock двух автономных meet: Mira timeout, ResidentA завершил встречу лишь после её освобождения. При занятости арбитра активная взаимная задача уступает по стабильному порядку имён: больший инициатор завершает failed(MEETING_COLLISION), меньший сохраняет свой голос/срок и ждёт обычный арбитр. Чужую задачу не переписываем, decline/чат выше столкновения, экономику не отменяем; новая игровая коллизия пока не наблюдалась.
2026-10-10 — Сервер выявил три двойных say Mira: модель одновременно указала args.text и say. В общем execute речевые say/whisper выполняют только свой native-навык, без публичного prelude; движение сохраняет речь. Это также исключает публичное раскрытие дополнительной реплики шёпота. Все brains обновлены под свободным manual-арбитром; живой say с обоими полями после внедрения ещё не появился. Повтор prelude при retry follow и взаимные одновременные meet отмечены отдельно, не объявлены исправленными.
2026-10-10 — Общая проверка порога регенерации повторяет native-плагин: rest запрещён при известном весе ≥50%; модель получает подсказку idle вместо невозможной регенерации. Fallback при низком HP/перевесе продаёт только прежний whitelist либо выбирает безопасный городской idle; смерть выше этих правил. Все brains обновлены через manual-арбитр, без отмены экономики; новые игровые rest/низкое HP в срезе не наблюдались, снятие перевеса не заявляем.
2026-10-10 — Модельный decline завершает meet независимо от доставки речи: один безопасный захват свободного manual-арбитра, без ожидания занятого writer; в meeting_reply отдельно сохраняем done/ошибку/неотправленную речь. Чат выше отказа, экономика не отменяется, встречное предложение сохраняет прежний срок. Живой accept после внедрения подтверждён; новая ветвь decline пока только make check.
2026-10-10 — После отдельного модельного голоса meet ждёт освобождения manual-арбитра второго жителя в пределах исходных пяти минут: модельная охота удерживает lock, мгновенный TARGET_BUSY терял настоящее согласие. Новый голос/срок не создаём, экономика не отменяется, чат прерывает ожидание; живое согласие и встреча подтверждены, отказ без озвучивания пока может закончиться timeout.

Запущенные gateways не перезапускаем ради внедрения; новый импорт и восстановление в игре должны быть подтверждены отдельно.
