# Hermes: два живых персонажа, DeepSeek + native JEV

База: `c6df504` из `claude/brain-coordinator`. Пользователь явно попросил включить интеллект и JEV для обоих существующих персонажей. Старое поручение остановить ботов отменено новым запросом.

## Выполнено
- Два существующих аккаунта: bot01 Arkady (Swordman), bot02 Vera (Acolyte); персонажей/аккаунты не пересоздавал. Профиль Mirela заменён на реальную Vera.
- До платных вызовов: 22 upstream-теста OK; оба моста подключились, rule-приветствия реально отправлены в игру и ack OK.
- Найдена несовместимость: upstream JevGate ожидал OpenAI chat/completions, настоящий TypeSafe — https://api.typesafe.ai/v1/systemone с {model,state,questions}, ответы Choice. Проверено по официальному adapter jev-layer eeb9f19 / src/providers/typesafe.mjs.
- Добавлен `live_brain/typesafe.py`: закрытый выбор deepseek/ignore, проверка confidence, никаких произвольных команд и генерации quick-текста. Таймаут/невалидный ответ — LLMError, затем существующий fallback правил. В gate выбор native adapter только для фиксированного HTTPS endpoint.
- Добавлены 4 offline-теста TypeSafe; RED без модуля, затем GREEN. Тесты персонажа выровнены на имя Vera. Все 26 тестов OK.
- Живые проверки: DeepSeek CHECK OK (1.8 с); JEV CHECK OK (0.3 с, confidence 0.680).
- Найдено: `ignoreAll 1` запрещал личку, а `serverEncoding Western` превращал русский в question marks. Исправлено на ignoreAll 0 и UTF-8 в обоих лабораторных профилях. Это проверка обмена бот↔бот; совместимость с отдельным RO-клиентом пользователя ещё не проверялась.
- Настоящий игровой тест: оператор дал Vera одну стартовую реплику через консоль OpenKore. Arkady получил её, JEV выбрал deepseek (0.3 с, 0.890), DeepSeek сформировал ответ, плагин отправил whisper, Vera получила ответ. Последующие ответы обоих — автономные, с JEV и DeepSeek.

## Наблюдённый диалог (последующие реплики без вмешательства)
Arkady → Vera: «Спасибо, Vera. Буду внимателен.»
Vera получила эту реплику → Arkady: «И ты береги себя, встретимся у костра вечером?»
Отправка и получение подтверждены console.log обоих, решения и ack — decisions.jsonl. Ack сам по себе недостаточен: до исправления ignoreAll тоже был ack, хотя сервер отвергал сообщения.

## Память
Отдельная SQLite для каждого в state/<bot>/memory.sqlite. У Arkady наблюдены 2 воспоминания и отношение к Vera (+2, «добрая аколитка, с которой приятно общаться»). У Vera отношение к Arkady (+1, «друг, с которым интересно общаться»). Перезапуск только brain-bot01: журнал показывает «память: 2 воспоминаний». Не обещаем полноценную симуляцию психики: это события, выбранные воспоминания, отношения, цель и настроение.

## Ограничения/стоимость
Локально: DeepSeek 100 запросов/24ч на персонажа, JEV 300/24ч на персонажа, план каждые 300с, повод общаться каждые 600с, ответы друг другу 6/час. Ключи только secrets/live_ro.env; env в Git не входит. Это лимиты количества, не денежный hard cap в аккаунте провайдера.
Сумма cost в usage записанных решений OpenRouter в момент замера: $0.007999; не включает check-запрос $0.0000524889, JEV и последующие запросы. Не выдавать это за полный счёт или тариф.

## Runtime
login/char/map не перезапускались в этой задаче. Оба игровых бота и оба мозга оставлены включёнными. bot02 работает в tmux live_ro_bot02 (tmux установлен для доступа к реальной игровой консоли). brain sockets локальные Unix.
